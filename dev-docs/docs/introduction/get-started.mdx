## Try now

Go to [coolskyai.com](https://coolskyai.com) to start sketching.

## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup and introduction.
- [@coolskydraw/coolskydraw](/docs/@coolskydraw/coolskydraw/installation) — docs for the npm package to help you integrate Coolskydraw into your own app.
- Editor — IN PROGRESS. Docs describing the internals of the Coolskydraw editor to help in contributing to the codebase.
- [@excalidraw/mermaid-to-excalidraw](/docs/@excalidraw/mermaid-to-excalidraw/installation) - Docs for the mermaid to coolskydraw parser
