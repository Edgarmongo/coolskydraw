# API

Currently the **API** is divided into 3 broad categories 👇

- [Props](/docs/@coolskydraw/coolskydraw/api/props) - The `props` you can pass to the `Coolskydraw` component.
- [Children components](/docs/@coolskydraw/coolskydraw/api/children-components) - Official components you can use to customize the UI.
- [Utils](/docs/@coolskydraw/coolskydraw/api/utils) - Utilities and helpers you can use to export, restore and more.
